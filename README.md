 - Ubuntu Linux OS preferred/wsl2

### Building the project
1. Create a directory in the terminal Using mkdir project-name. Use touch cooand to create a .html file.
2. Go to github account , navigate to the repository of choice or create a new repo. Copy the ssh that will be generated. 
3. Clone the repository to your machine. Use the git clone command:
   ```bash
   git clone https://github.com
   ```
4. In the same directory use code . command to open vs code:
   ```bash
   code .

5. After opening vs code, a blank html file should be visible.
6. In the blank page, is where the coding happens. Also a css file is added for the styling.
7. Do git add . ,git commit -m"message" , git push to add your work to your github repo, the one you had cloned.

##  Roadmap

1.  Head section
  - Meta data, title ie; My portfolio and links. Link to external css ie; portfolio.css, and another link to FontAwesome Library. 

2. Navigation bar 
  - contains titles ie home, about, education and contact, in an unordered list. The class navbar allows for further styling in the css file 
3. Home section
  - contains an image which and a text which is also styled further in the css document
4. About me section
- Contains hobbies, skills and what i enjoy in in a vertical display , and enclosed in three boxes further styling is made in the css file. 
5. Education section
- Brief section with ordered list of  my certifications.
6. Contact Section
 - The FontAwesome library is used here, for icons ie; phone, mail, github. Without the link to font awesome, the webpage would not understand what is written.
